# mos-pia-6520

The MOS 6520 peripheral interface adapter, and the Motorola 6821 it matches.

| Crate | Registry |
|---|---|
| [`emu198x-mos-pia-6520`](crates/emu198x-mos-pia-6520) | [crates.io](https://crates.io/crates/emu198x-mos-pia-6520) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Atari 800XL and Commodore PET.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
